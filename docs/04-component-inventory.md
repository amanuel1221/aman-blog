# Reusable Component Inventory

---

## 📌 Overview

This document defines all reusable UI components for the blog platform. These components will be used across multiple pages to ensure consistency and reduce duplicate code.

---

## 🎯 Why this matters

- Ensures UI consistency
- Reduces repeated code
- Makes frontend development faster
- Improves maintainability
- Helps align with Figma design system
